# 1. EXECUTIVE SUMMARY

## 1.1. Latar Belakang

Personal Portfolio Website ini merupakan website profesional yang dikembangkan untuk memperkenalkan identitas, kemampuan teknis, pengalaman, pendidikan, proyek, dan sertifikasi pemilik website.

Website ini ditujukan sebagai media personal branding untuk mendukung kebutuhan pencarian kerja, khususnya pada bidang Software Development dan Full-Stack Development.

Melalui website ini, recruiter, HR, hiring manager, maupun developer dapat memperoleh gambaran mengenai latar belakang pendidikan, pengalaman pengembangan perangkat lunak, kemampuan teknis, dan proyek yang pernah dikerjakan.

Website harus memiliki tampilan modern, minimalis, profesional, responsif, serta mudah digunakan pada berbagai perangkat.

1. Membangun personal branding sebagai lulusan Teknik Informatika yang berfokus pada pengembangan perangkat lunak.
2. Menampilkan pengalaman kerja dan organisasi secara profesional.
3. Menampilkan proyek pengembangan aplikasi dan sistem informasi.
4. Menyajikan kemampuan teknis berdasarkan teknologi yang pernah digunakan.
5. Menyediakan CV yang dapat diunduh dalam bahasa Indonesia dan Inggris.
6. Menampilkan sertifikasi yang relevan dengan bidang teknologi informasi.
7. Menyediakan sarana komunikasi melalui email dan contact form.
8. Membangun website yang mudah dikembangkan dan dipelihara.
